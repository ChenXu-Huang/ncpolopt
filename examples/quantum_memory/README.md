# Quantum-memory verification: numerical checks

This directory verifies the SDP derivation of the staged document
`verification-of-memory.md`: measurement-device-independent (MDI) verification
of a quantum memory, in the Rosset-Buscemi-Liang style (PRX 8, 021033 (2018) /
arXiv:1710.04710). The example under test is the depolarizing channel
`M_p(rho) = p rho + (1-p)/3 (X rho X + Y rho Y + Z rho Z)` with the identity
extraction map, whose Choi fidelity is exactly `p`.

Every claim of the document that can be computed is checked either numerically
(Part A, cvxpy/CLARABEL) or through the public ncpolopt API (Part B). The
scripts are intentionally standalone so each part can be re-run independently:

| File | Purpose |
| --- | --- |
| [common.py](common.py) | States, channel, Choi state, correlations (eq. (1) and eq. (10)), eq. (16) table, functional-class machinery, the three relaxation constructions |
| [verify_dual_sdp.py](verify_dual_sdp.py) | Part A: correlation tables and the two dual SDPs (eq. (6), eq. (9)) |
| [verify_relaxation.py](verify_relaxation.py) | Part B: the eq. (14) relaxation -- verbatim class form (L1), operator form (L1/L2) and factored NPA-tau re-expression (L2, certified) |
| [test_memory_verification.py](../../tests/test_memory_verification.py) | The same checks as self-contained pytest tests |

Run: `uv run python examples/quantum_memory/verify_dual_sdp.py`, likewise
`verify_relaxation.py` (both accept `--p 0.5` or `--p-grid 0.25,0.5,1.0`;
`verify_relaxation.py` also accepts `--n-outputs {1,4}` to select the
single-output or the full four-output Bell measurement), and
`uv run pytest tests/test_memory_verification.py` (the multi-minute
single-output L2 certification and the four-output solves are marked
`slow` and excluded from CI via `uv run pytest -m "not slow"`).

## Part A: correlations and dual SDPs (all passed)

* The three forms of the correlation agree to machine precision: eq. (1)
  `Tr[(M(rho_x) x sigma_y) Phi^alpha]`, eq. (10)
  `d Tr[(rho_x^T x I x sigma_y)(J_M x I)(I x Phi^alpha)]`, and the closed-form
  table eq. (16) (worst deviation ~4e-16 across the p grid, all 16 entries).
* The four-output probabilities sum to one: `sum_alpha p(alpha|x,y) = 1`.
* The Choi state of the depolarizing channel is the Werner state with fidelity
  `p` (eq. (15)), and `<phi+|J_M|phi+> = p` (eq. (4)).
* Strong duality holds: eq. (6) `max Tr(J_M J)` and eq. (9)
  `min Tr(Z)/d` both equal `p` to 1e-8 (see table).

| p | eq. (6) | eq. (9) | eq. (9) without `Z >= 0` |
| --- | --- | --- | --- |
| 0.30 | 0.30000000 | 0.30000000 | 0.30000000 |
| 0.50 | 0.50000000 | 0.50000000 | 0.50000000 |
| 0.75 | 0.75000000 | 0.75000000 | 0.75000000 |
| 1.00 | 0.99999999 | 1.00000000 | 1.00000000 |

The last column confirms the document's `Z >= 0` constraint is redundant:
`I^{A0} x Z >= J_M >= 0` already forces `Z >= 0`.

## Part B: the eq. (14) relaxation (certified, exact at level 2)

The relaxation of eq. (14) is built three times:

* **verbatim, class-parametrized** (`verbatim_relaxation_value`): the two
  moment matrices `M = Gamma^{(J_M)}` and `L = Gamma^{(Z)}` over the word
  basis with one SDP variable per functional class of `G_{u,v} =
  Tr_{B2}(v u^dagger)` (for `M`) resp. `H_{u,v} = Tr_{A0B2}(v u^dagger)`
  (for `L`), pins `M[V_alpha, U_{x,y}] = p(alpha|x,y)/d`, constraints
  `M >= 0, L >= 0, L - M >= 0`, objective `L[I, I]/d^3`.
* **operator-parametrized** (`operator_relaxation_value`): eq. (14) as
  written -- the entries are `M[u, v] = Tr[G_{u,v} J]` and
  `L[u, v] = Tr[H_{u,v} Z]` with the genuine Hermitian operators `J` (4x4)
  and `Z` (2x2) as the variables (20 real degrees of freedom).
* **factored NPA-tau** (`npa_tau_relaxation_value`): the same relaxation
  re-expressed as a standard NPA problem over the extended algebra
  `S union {J, W}` with state `tau = I_8/8`, solved through the public
  ncpolopt API (one output) or the package's direct sparse CLARABEL
  backend (four outputs; the dense cvxpy conversion cannot hold its
  moment matrix).

### The `(2p+1)/6` wall, and what actually breaks it

Earlier versions of this example could not get past the analytic line
`(2p+1)/6` (= the diagonal correlation `p(0|x,x)` of eq. (16)): every
construction -- level 1 or 2, one output or four -- sat exactly on it.
Controlled experiments (operator- vs class-parametrized forms, real vs
complex, with and without each relation family) isolate the cause
cleanly. Reaching `p` needs **all three** of:

1. **The probe words `U_{x,y} V_alpha`.** The document's word set
   `S-tilde` is the monomials generated by `S = {I, U, V}` (eq. (11)), so
   the degree-2 monomials `U V` belong to the level-2 word set. Without
   them the base word set spans only a 17-dimensional subspace of the
   64-dimensional operator space, and the `Gamma^{(Z)} - Gamma^{(J)} >= 0`
   moment test never sees the directions that couple the memory output
   `A2` to the measurement side `B2` -- the objective is then bounded by
   the diagonal correlation alone. (With the probes the span reaches 32
   at one output and the full 64 at four outputs.)
2. **The transpose `rho_x^T` on the `A0` side** (eq. (10)) in the
   factored re-expression. `rho_3 = |+i><+i|` is not symmetric; with the
   transpose forgotten, the correlation pins force the `J`-insert moments
   to those of the *non-PSD partial transpose* `J_M^{T_A0}`, so no
   genuine PSD `J` is consistent with the data and the relaxation can
   never be tight. (With the probe words present the untransposed model
   even turns infeasible at `p = 1` -- the strongest possible signature
   of the bug.)
3. **Functional linearity.** The moments of one inserted operator must be
   *linear* in the functional `G_{u,v}`: `m(u, v) = Tr[G_{u,v} J]` with
   one shared Hermitian `J`. The class parametrization (one free variable
   per class) drops exactly this cross-class linearity, and no finite set
   of word-identity lifts (completeness, Pauli products) replaces it: the
   class form stalls at `(2p+1)/6` even with the probe words added
   (0.333333 at p = 0.5; it reaches p only at the endpoint p = 1).

One plausible-sounding hypothesis is **refuted** by the experiments: the
wall is *not* a real-vs-complex artifact. The verbatim path is fully
complex throughout (complex class variables for the non-self-adjoint
functionals, and at level 2 the full complex Pauli-decomposition
relations `X_x X_z = sum_t c_t X_t` imposed entrywise) and still sits on
the wall; conversely the operator/factored forms reach `p` with purely
*real* SDP data (the pin functionals are Hermitian, and the real
relations among the Hermitian parts of the functionals suffice). The
`complex_matrix=False` realification of the factored path is harmless.

Evidence summary (single output, p = 0.5 unless noted):

| construction | value |
| --- | --- |
| verbatim class form, L1 | 0.333333 |
| verbatim class form, L2 + full complex Pauli relations | 0.333333 |
| verbatim class form + probe words | 0.333333 (1.000000 at p = 1.0) |
| operator form, L1 | 0.333333 |
| operator form, L2 (probe words) | **0.500000 = p** |
| operator form, L2, Re-only moments (realified) | **0.500000 = p** |
| factored NPA L2, no probes (the old construction) | 0.333333 |
| factored NPA L2, probes, no linearity family | 0.333333 |
| factored NPA L2, probes + linearity (the fix) | **0.499999 ~ p** |
| operator ceiling, untransposed `rho` (the transpose bug) | 0.333333, infeasible at p = 1 |

### The verbatim class-parametrized form (level 1 wall)

The word set carries the A0-/B2-side factors `X_x`/`W_y` of the U
operators, so the completeness relations are imposed entrywise on both
blocks (`M[u, X_0] + M[u, X_1] = M[u, I]` etc.). No trace-preserving pin
is used. The bound sits on the analytic line `(2p+1)/6` at level 1, for
one and four outputs alike:

| p | single-output L1 | 4-output L1 | `(2p+1)/6` |
| --- | --- | --- | --- |
| 0.25 | **0.250000** | **0.250000** | 0.250000 |
| 0.30 | 0.266667 | 0.266667 | 0.266667 |
| 0.50 | 0.333333 | 0.333333 | 0.333333 |
| 0.75 | 0.416667 | 0.416667 | 0.416667 |
| 1.00 | 0.500000 | 0.500000 | 0.500000 |

The wall is robust within this form: neither a trace-preserving pin nor
the generator completeness relations nor the Pauli-decomposition word
relations (tested in their strongest, full-complex form at level 2) go
past it. This is now understood: the class parametrization drops the
cross-class linearity (ingredient 3), and the word set lacks the probe
words (ingredient 1) -- both are structural, not numerical. The form is
kept as the demonstration of the eqs. (12)/(13) functional-class
structure; for the certified tight bound use the operator or factored
forms below.

### The operator form: exact at level 2

`operator_relaxation_value` keeps the genuine operators as variables, so
the functional linearity is exact by construction. Level 1 uses the
document's word set `S = {I, U, V}` (18/21 words); level 2 adds the
probe words `U_{x,y} V_alpha` (34/85 words). Level 1 sits on the wall;
level 2 attains the exact Choi fidelity `p`, for one and four outputs
alike:

| p | L1 (1 & 4 outputs) | L2 single-output | L2 4-output |
| --- | --- | --- | --- |
| 0.25 | **0.250000** | **0.250000** | **0.250000** |
| 0.30 | 0.266667 | **0.300000** | **0.300000** |
| 0.50 | 0.333333 | **0.500000** | **0.500000** |
| 0.75 | 0.416667 | **0.750000** | **0.750000** |
| 1.00 | 0.500000 | **1.000000** | **1.000000** |

(MOSEK; CLARABEL agrees on the single-output sizes. `M >= 0` and
`L >= 0` are implied by `J, Z >= 0` and not imposed separately; the only
inequality that constrains the objective is `Gamma^{(Z)} - Gamma^{(J)}
>= 0`, which is exactly what the probe words strengthen.)

### Level 2: the factored NPA-tau re-expression (certified, exact)

The correlations pin the degree-2 words `U J V`, so level 2 is the minimum
NPA level. The naive level-2 algebra `{U, V, J, W}` (364 words, ~6e4 SDP
variables, ~60 TB of dense materialization) is not solvable with the current
backends. Following the factored-algebra technique of Brown's user guide on
device-independent conditional-entropy bounds, the `U` operators are
re-expressed as `U_{x,y} = rho_x^T (x) I (x) sigma_y` on
`H_{A0} x H_{A2} x H_{B2}` (the transpose of eq. (10) -- see the diagnosis
above) with the one-direction commutation `rho_i sigma_j -> sigma_j rho_i`
and the orthogonal-input rules (`rho_0 rho_1 -> 0`, `sigma_0 sigma_1 -> 0`,
both orders -- the input states |0> and |1> are orthogonal, so those words
are identically zero and drop out of the basis). The probe words
`rho_x sigma_y v_0` (the degree-2 monomials `U_{x,y} V_0` of the document's
operator set) extend the localizing basis, and their `g`-products (`g` in
`{J, W}`) join the extramonomials so every localizing entry exists as a
block-0 moment.
The single-output moment matrix has 184 words (11279 SDP variables,
4810 moment-equalities; ~1 minute per construction plus a few minutes
per solve on the direct sparse CLARABEL backend). Class relations
that reference pinned or zero classes are not dropped:
`class_moment_equalities` emits them as constant-equalities on the free
class members, so the orthogonal-input reduction no longer loses
class-relation links. The available moment-equality families
(`_factored_classes`):

* The **functional-class equalities** of eqs. (12)/(13)
  (`class_moment_equalities`): moments whose functionals coincide share
  one SDP variable.
* The **completeness relations** of the generators:
  `rho_0 + rho_1 = I`, `sigma_0 + sigma_1 = I`, and (for four outputs)
  `sum_alpha v_alpha = I`, lifted to `<u g rho_0 w> + <u g rho_1 w> =
  <u g w>` etc. for every word pair `(u, w)` whose terms exist in the
  moment matrix.
* The **functional-linearity relations** (`_functional_linearity_equalities`):
  the remaining content of "the moments are linear in the functional".
  For each inserted operator the grid of `(u, v)` moments is grouped by
  SDP variable, a greedy pivot set of independent functional vectors is
  chosen (the pivots saturate the Hermitian dimension: 16 for the J
  block, 4 for the W block), and every other group's relation
  `m = sum_a A_a m_a` is emitted with the exact real coefficients from
  the functional algebra. This family alone (with the probe words)
  already certifies `p`, and it is the default: it is the smallest,
  linearly independent, and most solver-robust set.

Certified single-output L2 value at the README anchor point p = 0.5
(direct sparse CLARABEL backend; the default relation set is the
linearly-independent `"linearity"` family):

| p | factored L2 | exact `p` |
| --- | --- | --- |
| 0.50 | **0.499999** (MOSEK: 0.500000) | 0.50 |

within solver tolerance of the exact fidelity -- against `(2p+1)/6 =
0.333333` before the fix. The A/B controls (single output, CLARABEL,
p = 0.5):

| variant | value |
| --- | --- |
| no probe words (the old construction) | 0.333333 |
| probes, without the linearity family | 0.333333 |
| probes + linearity (the fix) | **0.499999 ~ p** |

(The transpose bug's signature -- wall at p = 0.5, infeasible at p = 1 --
was measured on the operator ceiling model of the untransposed
convention; see the diagnosis above.)

Solver note: the certified SDP is boundary-degenerate (the correlation
pins fix the Choi operator uniquely, so the feasible set has no strict
interior), and the interior-point backends are reliable only at the
anchor point measured above -- away from it CLARABEL may report
`NumericalError` and MOSEK `unknown` after long iterations. For grid
scans use the operator form (`operator_relaxation_value`), which has 20
variables and solves every point in about a second; the factored form is
the demonstration of the public ncpolopt API, certified at the anchor.

### The NPA-tau re-expression

`_npa_tau_problem` in [common.py](common.py) writes eq. (14) as a standard
ncpolopt problem over the factored algebra `{rho, sigma, v, J, W}` with the
maximally mixed state, projections `rho^2 -> rho, sigma^2 -> sigma, v^2 -> v`,
the one-direction commutation `rho_i sigma_j -> sigma_j rho_i`, and the
orthogonal-input rules `rho_0 rho_1 -> 0`, `sigma_0 sigma_1 -> 0` (both
orders, for the orthogonal states |0> and |1>). Every moment over the
62-word S-basis `{1, rho, sigma, v}` (plus the probe words) is pinned to
its trace value `Tr[word]/8` (by `ncpolopt.hierarchies.trace_moment_pins`), the
correlations pin `<rho_x sigma_y J v> = p(alpha|x,y)/(8d)`, and the
objective is `<W>` (which equals `Gamma^{(Z)}_{I,I}/8`). Four details were
hard-won:

* The localizing matrices run over the **42-word basis**
  `{1, rho, sigma, v} U {U_{x,y}} U {probe}`. The degree-2 `U` words and
  degree-3 probe words are admissible because their `g` products (32
  extramonomials `{J, W} . U_{x,y}`, 16 probe words, 32 more
  `{J, W} . probe`) are added as `extramonomials`, so every localizing
  entry monomial `u^dagger g w` (degree <= 7) exists as a moment-matrix
  entry.
* The `J`- and `W`-localizing blocks are tied to the moment matrix by
  **block-0 moment-equalities** encoding the functional classes of eqs.
  (12)/(13) (`G_{u,v} = Tr_{B2}(v u^dagger)` for `J`, `H_{u,v} = Tr_{A0B2}
  (v u^dagger)` for `W`), generated by
  `ncpolopt.hierarchies.class_moment_equalities` (the `"classes"`
  family). The variable of an entry
  monomial is created at the first upper-triangle occurrence of the monomial
  or of its canonicalized adjoint (the builder reuses the conjugate's
  variable); the helper reads those positions off a draft build of the
  relaxation rather than re-simulating the builder. Pinned (constant)
  classes are **not** dropped: the helper emits a constant-equality tying
  each free class member to the pinned value (dropping them instead
  weakens the relaxation -- the more moments are pinned, the more links
  would be lost).
* Moment-equalities are **necessary**: without them the localizing
  entries become independent variables and the objective degenerates.
  The default relation set is the linearity family alone; the class
  equalities (`"classes"`) and completeness equalities
  (`"completeness"`) remain available as additional families, and all
  three families together certify the same value (measured 0.499996,
  CLARABEL, p = 0.5).
* The **completeness relations** of the generators are available as linear
  moment-equalities on the inserted blocks (`_completeness_equalities`):
  `rho_0 + rho_1 = I`, `sigma_0 + sigma_1 = I`, and (four outputs)
  `sum_alpha v_alpha = I` become `<u g rho_0 w> + <u g rho_1 w> =
  <u g w>` etc. for every word pair whose terms exist in block 0
  (positions read off the same draft build; pinned terms fold into the
  constant). They are not in the default relation set (the linearity
  family subsumes their on-grid content) and are kept for A/B
  comparison.
* The orthogonal-input rules shrink the SDP (62 instead of 66 S-basis
  words); the class relations into the dropped zero classes survive as
  constant-equalities `var = 0`, so the reduction no longer weakens the
  relaxation.

### The four-output Bell measurement

`n_outputs=4` carries the full Bell measurement `{Phi^0, ..., Phi^3}`: the
algebra gains three measurement operators `v_1, v_2, v_3` (14 generators,
113 S-basis words), the probe words extend the localizing basis to 45
words, and the correlations pin all 64 entries
`<rho_x sigma_y J v_alpha> = p(alpha|x,y)/(8d)`. The moment matrix
cannot be materialized through the package's dense cvxpy canonicalization,
so `npa_tau_relaxation_value` routes the four-output solves
through the package's direct sparse CLARABEL backend (`solver="clarabel"`,
[clarabel_solver.py](../../src/ncpolopt/solvers/clarabel_solver.py): per
block, the upper-triangle COO mirrored to the lower, off-diagonal svec
entries scaled by sqrt(2), rows grouped NonNeg first, PSD triangle cones
after) -- the same SDP, without the dense intermediate.

Certified four-output L2 value (direct sparse construction, MOSEK;
247-word moment matrix, 18689 SDP variables, 9562 moment-equalities):

| p | L2 (4-output) | single-output L2 (reference) |
| --- | --- | --- |
| 0.50 | **0.500000** | 0.499999 |

attaining the exact fidelity like the single-output variant (pre-fix:
both stalled at `(2p+1)/6` = 0.333333). With the probe words and the
linearity relations in place, the extra outputs add nothing to the bound
(one output already certifies `p`) -- but the four-output run certifies
the same value from the full Bell measurement, matching the document's
protocol.

## Tests

`tests/test_memory_verification.py` mirrors the two scripts as pytest tests:
the correlation table, the two dual SDPs pinned to `p`, the L1 relaxation
lower bounds (with the measured values pinned to +/-1e-3 as a solver-change
tripwire), the operator-form level-2 exactness (`value = p` at 1 and 4
outputs), the factored NPA-tau L2 certification (a solve at p = 0.5,
pinned to `p` within +/-1e-3 in the certified window `(0, p]`, re-using the
shared construction of [common.py](common.py) rather than duplicating it),
and a construction-sizes test pinning the operator/basis/relation/variable
counts so a change in the reduction rules trips the test. The four-output
solves and the single-output L2 certification are marked `slow` and excluded
from CI (`uv run pytest -m "not slow"`); run them locally with
`uv run pytest -m slow tests/test_memory_verification.py`. All numerical
tests use CLARABEL or MOSEK explicitly and follow the project conventions
(tolerance 1e-5, no RNG dependence).
